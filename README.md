# AI Resume Analyzer

An AI-powered web application that analyzes resumes and provides detailed feedback to help improve resume quality and ATS compatibility.

## 🚀 Features

- Upload resumes in PDF format
- AI-generated resume analysis
- Resume scoring and feedback
- ATS compatibility evaluation
- Clean and responsive user interface

## 🛠️ Tech Stack

- React
- React Router v7
- TypeScript
- Vite
- Tailwind CSS
- Puter.js
- Google Gemini 2.5 Flash

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Realadityapathak/Resume-Intelligence.git
```

Navigate to the project folder:

```bash
cd Resume-Intelligence
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open **http://localhost:5173** in your browser.
